What's new

  • Manage Remote Control from the menu bar menu: turn it on or off, switch each shared folder between Read-Only and Read/Write, share a new folder with "New Shared Folder…", or stop sharing one with "Remove…".
  • Setup now syncs every folder except "Camera Uploads" by default, and lets you choose whether Remote Control can only read your shared folder or also change it.
  • Large files sync without being loaded into memory all at once, and Remote Control transfers retry and resume after a dropped connection.
  • Folders you exclude from or bring back into sync through Remote Control take effect right away, without restarting Brick.

Fixes

  • Brick no longer fails to read its settings after Remote Control folders were set to Read/Write by the Brick command-line tool.
  • Clicking a menu item that opens a submenu no longer closes the menu.
  • Setup's sync step opens faster on large accounts.
  • Error messages now say what went wrong instead of "Something went wrong".
